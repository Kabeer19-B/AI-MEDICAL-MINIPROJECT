# MediFlow Hospital Workflow Demo

A local college-demo hospital workflow application with fictional data.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal, normally `http://localhost:5173`.

## Features

- Demo roles for Doctor, Nurse, Hospital Admin, and Patient
- Browser speech recognition for doctor notes
- Local ICD-10 demo suggestions with doctor verification
- Doctor-only treatment approval
- Nurse medication/injection completion workflow
- Patient daily reports with local JSON mock data

All patient information is fictional and for demonstration only.
